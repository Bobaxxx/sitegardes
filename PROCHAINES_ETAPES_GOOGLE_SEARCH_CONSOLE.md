## 📋 ÉTAPES À FAIRE MAINTENANT

### 1️⃣ VÉRIFIER L'INDEXATION DES PAGES

**Dans Google Search Console :**

1. Allez sur : **https://search.google.com/search-console**
2. Sélectionnez votre propriété : **gpserrurerie.fr**
3. Dans le menu de gauche, cliquez sur **"Indexation"** → **"Pages"**
4. Vérifiez que vos pages principales sont indexées :
   - ✅ Page d'accueil (`/`)
   - ✅ Services (`/services.html`)
   - ✅ Réalisations (`/realisations.html`)
   - ✅ Contact (`/contact.html`)

**⏱️ Si les pages ne sont pas encore indexées :**
- C'est normal, cela peut prendre 1 à 7 jours
- Vous pouvez demander l'indexation manuelle (voir étape 2)

---

### 2️⃣ DEMANDER L'INDEXATION MANUELLE (RECOMMANDÉ)

**Pour accélérer l'indexation de votre page d'accueil :**

1. Dans Google Search Console, allez dans **"Indexation"** → **"Pages"**
2. Cliquez sur **"Demander l'indexation"** (en haut à droite)
3. Entrez l'URL : `https://gpserrurerie.fr/`
4. Cliquez sur **"Demander l'indexation"**
5. ⏳ Attendez quelques heures (Google va crawler votre page)

**💡 Astuce :** Vous pouvez aussi demander l'indexation pour :
- `https://gpserrurerie.fr/services.html`
- `https://gpserrurerie.fr/realisations.html`
- `https://gpserrurerie.fr/contact.html`

### 3️⃣ VÉRIFIER LE STATUT DU SITEMAP

**Dans Google Search Console :**

1. Menu de gauche : **"Sitemaps"**
2. Vérifiez que le statut est **"Réussi"** (✅)
3. Vérifiez le nombre de pages découvertes :
   - Vous devriez voir **6 pages** découvertes

### 5️⃣ VÉRIFIER LES ERREURS D'INDEXATION

**Dans Google Search Console :**

1. Menu de gauche : **"Indexation"** → **"Pages"**
2. Cliquez sur **"Exclues"** (onglet)
3. Vérifiez s'il y a des pages exclues et pourquoi :
   - Si vous voyez des erreurs, corrigez-les
   - Les erreurs courantes : pages 404, pages bloquées par robots.txt, etc.

1. Allez sur : **https://search.google.com/test/rich-results**
2. Entrez l'URL : `https://gpserrurerie.fr/`

## 🆘 EN CAS DE PROBLÈME

**Si le sitemap ne fonctionne pas :**

1. Vérifiez que `https://gpserrurerie.fr/sitemap.xml` est accessible
2. Vérifiez que le sitemap est bien formaté (XML valide)
3. Supprimez et resoumettez le sitemap dans Google Search Console

**Si les pages ne sont pas indexées après 2 semaines :**

1. Vérifiez que votre `robots.txt` n'interdit pas l'indexation
2. Vérifiez qu'il n'y a pas de balise `noindex` dans vos pages HTML
3. Contactez le support Google Search Console
